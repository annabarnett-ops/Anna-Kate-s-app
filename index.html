How I Built This
By Anna Katherine Barnett  ·  Vocab Smackdown · Coding Vocabulary Edition

The Concept

Vocab review shouldn't feel like a chore — it should feel like a game with real stakes. I wanted something that would make me want to study. The idea was simple: show a definition, pick the right term from four choices, and protect your three lives. Add a power bar so you always know how close you are to winning, and suddenly vocabulary practice has a heartbeat.

🌸 ✨ 🌸

The Aesthetic

I went with a soft, pastel-maximalist direction — light teal and blush pink as the core palette, layered with warm cream backgrounds, delicate dot textures, floating gradient blobs, and a custom sparkle cursor. The goal was something that felt beautiful and polished without being overwhelming.

Typography is a big part of the personality: Playfair Display brings that elegant, editorial serif energy to the titles and question text, while Nunito keeps everything else rounded and friendly. Together they create a soft-luxury feel that's still readable and functional.

🌸 ✨ 🌸

The Game Logic

At the start, all 15 words are shuffled randomly. Each round picks the current word's definition as the question, then generates 3 decoy terms from the remaining pool — always unique, never repeating the correct answer as a distractor. The four choices are shuffled so the right answer isn't always in the same spot.

A wrong answer deducts a life. A correct answer advances the Power Bar by ~6.67%. Lose all 3 lives and it's Game Over. Answer all 15 before that happens, and you achieve Total Vocabulary Domination. The correct answer is always revealed after a wrong guess, so you learn as you go.

🌸 ✨ 🌸

Special Touches

A few details I'm proud of: the background uses pure CSS radial gradients layered with a dot texture pseudo-element — no images. The floating blobs animate with a slow blobDrift keyframe. Correct answers fire a burst of colored circles generated dynamically in JavaScript, flying outward in random directions. The card re-triggers its pop animation on every round using a reflow trick (offsetWidth) so the entrance always fires fresh. The custom cursor is an inline SVG data URI — sparkle emoji, zero external files.

🌸 ✨ 🌸

Tech Stack

One file. No frameworks. No build tools. Just HTML, CSS, and vanilla JavaScript — plus Google Fonts for typography.
